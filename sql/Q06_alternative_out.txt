| Strategy         | Description                        | Advantage                                           | Disadvantage                                     |
+------------------+------------------------------------+-----------------------------------------------------+--------------------------------------------------+
| Default Join     | Optimizer chooses best strategy    | Baseline for comparison                             | May not always choose optimal plan               |
| Nested Loop Join | Good for small tables with indexes | Efficient when filtering reduces rows significantly | Poor performance on large tables without indexes |
| Hash Join (BNL)  | Good for large unindexed tables    | Works well when indexes are missing                 | Memory intensive for large datasets              |
| Merge Join       | Good when data is already sorted   | Efficient for large sorted datasets                 | Requires sorted input or indexes                 |
